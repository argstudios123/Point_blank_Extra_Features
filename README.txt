# Welcome to Vics Point Blank Extra Features!


Adds more customizable features to Vic's Point Blank, designed to give content pack creators more control over their weapons and improve the over all gameplay experience.


Here are the Following features this mod adds

- Toggleable Aiming – Toggle aiming on and off with a single button press.
- Melee System – Add custom melee attacks with configurable damage, cooldowns, reach, and animations.
- In game Ammo and  heat Ui Editor Screen – Create and customize ammo Ui with an easy-to-use in-game UI editor screen , save tons of time when making custom hud for your weapons
- Reserve Ammo Counter – Display the remaining compatible ammunition in your inventory.
- ADS Reload Constraint – Adds Support of reloading while in Aiming , fully customizable  
- Multiple Weapon Sounds – Allows the use of multiple gun sounds to be used when firing .
- Unlimited Magazine Capacity Fix – Allowes the Use of Unlimited magazine Capacity feature to be used inside firing mods which Default VPB doesnt allows and crashes the game
- Environmental Shooting Effects – Add water and lava particle effects when shooting into them.
- JSON Configuration – Customize supported features through weapon configuration files.
- UI Reload Commands – Reload UI definitions without restarting the game.
 
# Content Pack Creators

Point Blank Extra Features aims to expand the possibilities of Vic's Point Blank by introducing additional customization options and tools for content pack creators.
Create custom ammunition displays, configure weapon mechanics, and fine-tune supported features to suit your content pack.
